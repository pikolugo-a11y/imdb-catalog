# PikoFilm V5 — Decisión 40

## Mejora 40 · V5-C040 — Historial contextual de cambios en la ficha de un título

**Estado:** RECHAZADA  
**Prioridad definitiva:** No entra en V5.  
**Categoría:** Catálogo · UX · Trazabilidad funcional

**Propuesta evaluada**

Añadir en la ficha de cada película o serie un bloque de “Cambios recientes” con hechos funcionalmente relevantes del título —por ejemplo cambios de Calidad, detección en Plex, correcciones o paso por determinados procesos— y enlaces al detalle correspondiente cuando existiera.

**Motivo de rechazo del usuario**

El usuario no quiere añadir este bloque contextual en la ficha de cada título.

**Consecuencia para V5**

- No se añadirá historial reciente dentro de la ficha de películas o series.
- Actividad y Operaciones seguirán siendo las superficies canónicas para consultar hechos funcionales y trazabilidad técnica.
- No se duplicará esa información dentro de cada ficha.

**Resultado esperado para el usuario**

Las fichas permanecerán centradas en la información propia del título, sin añadir otro bloque de historial que el usuario no necesita.

**Decisión del usuario:** rechazada.
