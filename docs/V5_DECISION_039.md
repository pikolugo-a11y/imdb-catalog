# PikoFilm V5 — Decisión 39

## Mejora 39 · V5-C039 — Comparar títulos lado a lado

**Estado:** RECHAZADA  
**Prioridad definitiva:** No entra en V5.  
**Categoría:** Catálogo · UX · Funcionalidad

**Propuesta evaluada**

Permitir seleccionar dos o varios títulos del Catálogo y abrir una comparación directa de datos como nota, votos, año, duración, Calidad, estado en Plex y otros campos relevantes.

**Motivo de rechazo del usuario**

El usuario no quiere añadir una función específica de comparación entre títulos en V5 y prefiere no dedicar alcance a una capacidad de conveniencia que no resuelve un problema actual.

**Consecuencia para V5**

- No se añadirá selección múltiple orientada a comparación.
- No se creará una pantalla o modal de comparación de títulos.
- Catálogo seguirá centrado en búsqueda, filtrado, ordenación, rendimiento y detalle individual.

**Resultado esperado para el usuario**

V5 no añadirá complejidad visual ni lógica adicional para comparar títulos lado a lado y concentrará el trabajo en mejoras con impacto más directo.

**Decisión del usuario:** rechazada.
