# PikoFilm V5 — Decisión 53

### Mejora 53 · V5-C053 — Enlaces desde una entidad a sus ejecuciones recientes

**Estado:** RECHAZADA  
**Prioridad definitiva:** No entra en V5.  
**Categoría:** UX · Operaciones · Navegación contextual

**Propuesta evaluada**

Añadir desde fichas o entidades funcionales enlaces contextuales hacia Operaciones ya filtrado para consultar ejecuciones técnicas recientes relacionadas con esa película, serie u otra entidad.

**Motivo de rechazo del usuario**

El usuario no quiere añadir este acceso contextual como parte de V5. Prefiere mantener la navegación actual y consultar Operaciones directamente cuando necesite investigar una ejecución.

**Consecuencia para V5**

- No se añadirán enlaces desde fichas de títulos hacia Operaciones filtrado por entidad.
- No se incorporará historial técnico embebido ni accesos equivalentes en las fichas.
- Operaciones seguirá siendo la superficie canónica para diagnóstico técnico y trazabilidad de ejecuciones.
- Esta decisión no afecta a la Mejora 52 aprobada, que sí mejorará la relación visual entre ejecuciones padre, hijas y continuaciones dentro de Operaciones.

**Resultado esperado para el usuario**

Las fichas se mantendrán más limpias y sin accesos técnicos adicionales. La investigación operativa seguirá concentrada en Operaciones.

**Decisión del usuario:** rechazada.
