# PikoFilm V5 — Decisión 45

## Mejora 45 · V5-C045 — Hacer más útil “Lo que dice tu filmoteca”

**Estado:** RECHAZADA  
**Prioridad definitiva:** No entra en V5.  
**Categoría:** Inicio · UX · Análisis

**Propuesta evaluada**

Convertir el bloque “Lo que dice tu filmoteca” en una superficie con conclusiones temporales o accionables, por ejemplo comparativas semanales/mensuales, evolución de pendientes o avisos interpretados a partir de históricos.

**Motivo de rechazo del usuario**

El usuario no quiere ampliar este bloque con nuevas conclusiones temporales/accionables como funcionalidad de V5.

**Consecuencia para V5**

- No se añadirán nuevos mensajes interpretativos temporales ni comparativas automáticas dentro de “Lo que dice tu filmoteca”.
- Inicio seguirá centrado en mostrar la información ya aprobada, priorizando además las mejoras de rendimiento y coherencia ya aceptadas.
- Esta decisión no impide corregir datos erróneos ni reutilizar snapshots existentes para funcionalidades ya vigentes.

**Resultado esperado para el usuario**

Inicio se mantiene más directo y sin añadir una nueva capa de interpretación que el usuario no considera necesaria.

**Decisión del usuario:** rechazada.
