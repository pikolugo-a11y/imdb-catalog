# PikoFilm V5 — Decisión 38

## Mejora 38 · V5-C038 — Guardar vistas completas de Catálogo

**Estado:** RECHAZADA  
**Prioridad definitiva:** No entra en V5.  
**Categoría:** Catálogo · UX · Conveniencia

**Propuesta evaluada**

Permitir guardar una vista completa de Catálogo con filtros, ordenación y configuración de visualización para recuperarla después con un nombre.

**Motivo de rechazo del usuario**

El usuario no quiere añadir vistas guardadas de Catálogo y ya había rechazado también los presets de filtros de la Mejora 37. Prefiere mantener Catálogo directo y sin estado persistente adicional de este tipo.

**Consecuencia para V5**

- No se añadirá un sistema de vistas guardadas.
- No se persistirán combinaciones de filtros, ordenación o presentación como funcionalidad de producto.
- Catálogo mantendrá su navegación y configuración actual sin añadir gestión de vistas personalizadas.

**Resultado esperado para el usuario**

Catálogo seguirá siendo simple y directo, sin menús ni estados adicionales para guardar o recuperar configuraciones completas de vista.

**Decisión del usuario:** rechazada.
