# PikoFilm V5 — Decisión 46

### Mejora 46 · V5-C046 — Comparativas temporales configurables en Inicio

**Estado:** RECHAZADA  
**Prioridad definitiva:** No entra en V5.  
**Categoría:** Inicio · UX · Analítica · Conveniencia

**Propuesta evaluada**

Permitir cambiar desde Inicio la ventana temporal de determinadas métricas o comparativas, por ejemplo últimos 7, 30 o 90 días, en lugar de mantener una única referencia temporal fija.

**Motivo de rechazo del usuario**

El usuario no quiere añadir esta funcionalidad en V5 y prefiere no introducir más controles ni lógica analítica en Inicio sin una necesidad funcional clara.

**Consecuencia para V5**

- Inicio no añadirá selectores de ventana temporal 7/30/90 días ni equivalentes.
- Las métricas existentes mantendrán sus referencias temporales actuales salvo que otra mejora aprobada requiera un ajuste concreto.
- No se añadirá complejidad de estado, consultas o UX para comparativas temporales configurables.
- Esta decisión no impide reutilizar snapshots o datos temporales ya existentes cuando sean necesarios para otras mejoras aprobadas.

**Resultado esperado para el usuario**

Inicio seguirá siendo más simple y centrado en la información útil ya definida, sin controles adicionales para explorar periodos temporales que el usuario no necesita.

**Decisión del usuario:** rechazada.
